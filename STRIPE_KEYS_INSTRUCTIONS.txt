STRIPE API KEYS - INSTRUCTIONS
====================================

From your Stripe dashboard, get your API keys:

SECRET KEY (for backend):
- Format: sk_test_... or sk_live_...
- Find at: https://dashboard.stripe.com/apikeys

PUBLISHABLE KEY (for frontend):
- Format: pk_test_... or pk_live_...
- Find at: https://dashboard.stripe.com/apikeys


HOW TO ENTER THEM IN REPLIT:
=============================

1. Go to Replit Secrets (lock icon on left sidebar)

2. Find or create: STRIPE_SECRET_KEY
   - Click Edit or Add
   - Paste your Secret key (starts with sk_test_ or sk_live_)
   - Save

3. Find or create: VITE_STRIPE_PUBLIC_KEY
   - Click Edit or Add
   - Paste your Publishable key (starts with pk_test_ or pk_live_)
   - Save

4. Restart the application to apply changes


COMMON MISTAKES TO AVOID:
==========================
- Only copying part of the key (missing sk_test_ or pk_test_)
- Swapping the keys (putting secret in public, or vice versa)
- Extra spaces at beginning or end
- Copy the COMPLETE key from sk_test or pk_test all the way to the end


SECURITY:
=========
- NEVER commit actual API keys to your codebase
- Use environment variables or secrets management
- Rotate keys if they are ever exposed
